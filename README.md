## 📖 Project Overview

**MoneyBook** is a mini web application developed for the **EEI3346 – Web Application Development Mini Project** module.

The project is designed around the theme of **banknote collecting**, presenting note-related content through multiple pages, visual assets, and a structured frontend layout. It highlights the user’s interest in collecting banknotes while demonstrating practical web development skills using core frontend technologies.

This project focuses on:

- clean user interface design  
- structured page navigation  
- visual presentation of banknotes  
- frontend interaction using JavaScript  
- responsive and organized web layout  

---

## ✨ Key Features

- 🏠 Home page with introduction
- ℹ️ About page
- 💵 Separate pages for different banknotes
- 🖼️ Image-based visual presentation
- 🎥 Video media included in the project
- 📱 Responsive frontend layout
- 🧭 Simple and user-friendly navigation
- 📞 Contact information section
- 💬 Comment / terms related pages
